# C++ conventions

The C++ rules are the `cpp-*` skills in `$HOME/ai/skills/`. Start with
`cpp-principles/SKILL.md`. The C++ section of `$HOME/ai/AGENTS.md` lists the
skill for each kind of work. Naming and layout are in
`cpp-naming-and-layout/SKILL.md`.

This file stays so that existing references to `conventions/cpp.md` keep
working.
