# Global guidance

Use [ASD-STE100 Simplified Technical English](https://www.asd-ste100.org/)
for all written communication. Use short, active sentences and consistent
technical terms. Explain unfamiliar terms. Give one instruction per sentence
and number procedure steps. Do not use idioms or contractions. Preserve exact
identifiers, commands, paths, API names, and quotations. Consult the specification
when a word or rule is unclear.

Before C++ changes or review, read `$HOME/ai/conventions/cpp.md`.
Keep conventions for other languages in separate files under
`$HOME/ai/conventions/` and reference them here.
